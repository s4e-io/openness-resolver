# Code of Conduct

S4E (Security For Everyone): security should not be a privilege. This project is open so anyone can read it, trust it, and improve it.

- **Be direct and respectful.** Critique code and claims with evidence, never the person.
- **Everyone is welcome.** Answer questions kindly, review first pull requests properly, credit people.
- **Stay safe.** Report vulnerabilities privately (see `SECURITY.md`). Never post real host, customer, or credential data. Only test systems you are allowed to test.
- **No harassment, discrimination, or doxxing.**
- **Be honest.** AI tools are fine, but you own what you submit. Verify before you claim.

Maintainers may edit, remove, or reject contributions and ban accounts that break these rules.

Report a problem: **info@s4e.io**
